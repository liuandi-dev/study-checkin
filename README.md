# 📅 学习打卡日历

> 100 项目挑战 · 项目 #016 · 方案由 Andy 自己撰写（Day 7 · localStorage 周第 2 课）

每天学习后点开今天的格子，记下"学了什么 + 有哪些收获"；支持补昨天的卡；点已打卡的格子可回看或修改。本月日历打了变色，顶部显示连续坚持天数。

## 文件结构

```
study-checkin/
├── index.html   页面结构
├── style.css    样式（7 列日历网格、格子状态色）
└── script.js    逻辑（日期钥匙、对象存储、连续天数）
```

## 技术点

- **数据形状升级**：从 Todo 的数组 → 这次的对象，`"2026-10-24"` 日期字符串当钥匙
- **日期钥匙固定格式补零**（`padStart`）：字符串比大小 = 比日期先后
- **连续天数算法**：从今天往前一天天跳（`prevDayKey`），断链即停
- **本月日历生成**：1 号对齐星期、补前置空白、正方形格子网格

## 本地预览

双击 `index.html`；F12 → Application → Local Storage 可看到以日期为钥匙的数据。
